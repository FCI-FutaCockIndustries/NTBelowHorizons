### Декларация положений сборки
Прошу воздержаться от редактуры данного файла, помимо :  
Установки маркера "Y{ник} :  " в отдельной строке перед вопросом в случае подтверждения положения и "N{ник} :  " в случае опровержения положения, пример :  
```md
### Общий порядок взаимодействия с данжеонами
YMahiron47 :  
1. Наличие в данжеонах ключевого для продвижения игрока лута
NMahiron47 :  
2. Система усложения внутреннего контингента данжеона в соотвествии с этапом продвижения игрока по глобальной квестовой линии
```
если же перед положением отсуствует пустая строка, то положение считается необходимым и основополагающим
### Вне геймплейный порядок  
1. Наличие системы прессетов конфигураций сборки, в которой обязательно должна присутствовать основная конфигурация, которая будет максимально, насколько это допустимо, приемлима для среднего игрока по моральным ориентирам и играбельности, приэтом она должна быть сложна, хаотична, но прогнозируема, для прессетов должно быть выделено GUI, "Система прессетов" - это система на базе GUI, собирающая совокупность настроек конфига сборки в "Модули", позволящая отключением/включением модулей, выставлять значения совокупности настроек в конфигурациях модов на такие, которые изменят поведение сборки, согласно описанию модуля
  
2. GUI системы прессетов должна быть скрыта за пунктами дополнительной настройки.  
  
3. GUI системы прессетов должно позволять создать новый прессет.  
  
4. При выборе прессетов имеющих спорные темы, игрок должен быть об этом предварительно осведомлён, подтвердив свой выбор.
