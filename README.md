# NTBelowHorizons
Это модпак, преследующий цель в виде полной переработки геймплейного процесса майнкрафта, а также обеспечения наивысшей сложности среди всех аналогичных модпаков, версия модпака 1.20.1 ядро загрузчика fabric, геймплей в основном базируется на совмещении лучших тех модов на майнкрафт разных версий с балансировкой механик под нужды геймплея
